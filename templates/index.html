Example workflow GUIDANCE ONLY

name: JEMI CI
on:
  push:
    branches: [main]
  pull_request:
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.10"
      - run: pip install -r requirements.txt
      - run: pytest        # add tests/ first
      - run: docker build -t jemi:ci .   # needs a Dockerfile

About JEMI

JEMI DevOps Control Center is a Flask-backed monitoring dashboard built for an ISE-2 DevOps and Kubernetes practical. It shows real host metrics today and has honest placeholders for Docker, CI/CD and incidents until they are connected.
